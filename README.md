# Valuations

Metodologia e bibliografia para valuation (DCF) de empresas listadas.

- `metodologia/LISTA_FICHAMENTOS.md`: plano dos fichamentos (temas, fontes, prioridades).
- `metodologia/fichamentos/`: um fichamento por tema, cruzando Damodaran (*Investment Valuation*, 2ª ed., 2002) e Póvoa (*Valuation: Como Precificar Ações*, 2012).
